### 1. PaperOrchestra — google-research/paper-orchestra

- **主语言 / 技术栈：** Python 3.11、Conda、LaTeX、多代理工作流；可配置 Gemini/Vertex AI、OpenAI、Semantic Scholar 等服务。
- **主题标签 / 许可证：** AI、Python、研究工具；Apache-2.0（已核对仓库 `LICENSE`）。

- **首次发布 / 最近更新：** 2026-05-01 建仓；最近推送 2026-11-15；未见 GitHub Release。
- **简要介绍：** 将研究想法和实验日志转为 LaTeX 论文草稿的多代理框架。

- **适用场景：** AI 论文写作流程研究、实验记录整理、科研辅助工具原型。生成内容仍需作者逐项复核，不能替代研究贡献和学术署名责任。
