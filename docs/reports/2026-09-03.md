- **仓库地址**：https://github.com/varunsalian/debrify
- **官网**：https://debrify.tv
- **主语言 / 技术栈**：Dart、Flutter 3.8+、media_kit/libmpv、SQLite、WebDAV
- **主题标签**：Flutter、Windows、跨端桌面、媒体播放器、移动/电视
- **许可证**：AGPL-3.0-only；第三方组件/素材各自授权，项目名称与 Logo 另受商标策略限制。
- **当前 Star**：491
- **近期 Star 增长**：**周增 21（精确）**，来自 GitHub Trending Dart 周榜；相对当前体量约 4.3%/周。
- **首次发布 / 最近更新**：创建于 2025-08-02；最近 Push 为 2026-09-03；`v0.9.0-beta.1` 发布于 2026-09-01。
- **简要介绍**：把用户自有云盘、WebDAV、IPTV、插件目录与播放追踪集中到一个 Flutter 跨端媒体中心。
- **详细介绍**：Debrify 内置基于 media_kit/libmpv 的播放器、下载管理、字幕、播放列表与电视遥控交互，并提供 Android/Android TV、Windows、macOS、Linux、iOS、Apple TV 产物。项目声明不托管或捆绑媒体源，内容服务由用户自行配置。
- **核心能力**：跨端媒体库、原生长视频播放、WebDAV/云盘、下载、字幕、电视 D-pad、播放历史同步。
- **适用场景**：Flutter Windows 桌面、手机/桌面/TV 共用 UI、libmpv 原生依赖、文件系统、下载管理和多平台打包研究。
- **为什么近期快速上升**：周增 21 的绝对值不高，但相对不足 500 Star 的体量增速明显；两天前发布包含多端安装包的 beta 版本，且抓取当日仍有提交。
- **活跃度与成熟度**：多端可运行并有实质产品功能，但版本仍为 0.9 beta；维护者在 README 中明确承认历史代码和架构清理滞后，适合参考交付链路，不宜直接视作 Flutter 最佳实践。
- **Flutter 平台与 Windows 说明**：明确支持 **Windows 10/11、Android、Android TV、iOS、macOS、Linux、Apple TV**，当前无 Web 版本。Windows 已提供 Setup EXE，功能表述为全平台完整支持，完成度较高；源码构建使用 `flutter build windows --release`，播放器依赖 `media_kit/libmpv`，桌面还涉及 SQLite、文件权限和原生播放器动态库。Linux 需额外安装 libmpv、sqlite、FUSE；iOS/tvOS IPA 未签名且个人侧载通常每 7 天重签。Windows 发布仍应自行核验代码签名、安装器信誉、原生 DLL 打包和自动更新策略。
- **潜在风险或注意事项**：媒体源、IPTV、插件和下载行为可能涉及版权与服务条款，只应连接自己拥有或获授权的内容。AGPL 网络交互与分发义务、商标限制、beta 稳定性和原生播放依赖都需在产品采用前评估。
