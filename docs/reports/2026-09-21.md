## 1. AutoClip

- **官网：** https://zhouxiaoka.github.io/autoclip_intro/
- **主语言/技术栈：** Python、FastAPI、Celery、Redis、SQLite、FFmpeg、React/TypeScript。

**简要介绍：** 用模型分析长视频并自动提取高光片段、生成短视频的开源工具。

**详细介绍：** 它组合视频下载、转录与语义分析、片段选择、FFmpeg 剪辑、任务队列及 Web 界面。既可调用云端模型，也可接入 Ollama/LM Studio 等本地模型。新版把 `autoclip` 命令行与 MCP 服务接入桌面工作流，使脚本或 Agent 能启动、查询剪辑任务。

**适用场景：** 媒体素材批处理、视频二创、Python 多媒体流水线、Agent 调度创作工具；Windows 用户可评估项目提供的桌面安装包，服务端开发环境仍需按文档准备依赖。

**为什么近期快速上升：** 日榜 +395，同时 v1.3.0 刚加入 CLI 和 MCP。推断“可由 Agent 调用的本地视频工具”提升关注度；不能认定版本发布是全部 Star 增长的唯一原因。

**活跃度与成熟度：** 2025 年创建，近期仍有提交和版本；已有桌面包，但 README 中移动体验、字幕编辑及上传等功能仍标为开发中。

**风险或注意事项：** 下载、转载和训练/处理素材要遵守版权及平台规则；云模型会涉及素材外传与费用，本地模型需要性能资源。FFmpeg、Redis、容器或桌面包的运行条件须按所选部署方式核实。README 内早期徽章与安装说明可能未完全同步新版本。
