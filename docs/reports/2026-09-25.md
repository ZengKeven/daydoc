**详细介绍：** Model Optimizer 为 Hugging Face、PyTorch 和 ONNX 模型提供量化、剪枝、神经架构搜索、蒸馏、稀疏化及推测解码等技术，再导出适用于 TensorRT-LLM、TensorRT、vLLM 和 SGLang 等推理框架的检查点。它覆盖从训练后优化到部署前导出的链路，适合对速度、显存和精度做系统权衡。

**核心能力：** PTQ/QAT 量化、NVFP4/FP8 等低精度格式、剪枝与蒸馏、模型导出、与 NVIDIA 推理生态集成。

**适用场景：** Python 推理服务、LLM/VLM 压缩、GPU 成本优化、不同量化配置的性能和质量对比。

**为什么近期快速上升：** 0.47.0 刚发布，README 同期新增 Qwen3.6 的 W4A4/NVFP4 教程，且进入日榜；这两项与 +44 Star 同时出现，但不能据此证明单一传播原因。

**风险或注意事项：** README 中的吞吐和精度数字来自特定模型、硬件及基准，不能直接套用到自己的工作负载。NVFP4 等路径依赖兼容 GPU、CUDA 与下游框架版本；量化后必须重新评测任务质量。
