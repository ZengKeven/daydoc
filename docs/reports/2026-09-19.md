**适用场景：** Vue/Electron 管理端、Flutter 移动与桌面应用、Python/C# 服务的统一数据与鉴权后端；快速构建带实时和文件能力的产品。

**为什么近期快速上升：** 大型成熟仓库仍进入日榜并新增 120 Star，说明后端即服务与 AI 数据栈持续受关注；最近推送频繁。不能把总 Star 或月度 Release 当作当天新增功能证据。

**活跃度与成熟度：** 多年维护、生态成熟；各组件独立演进，自托管版本与托管平台在运维和功能上不能默认完全一致。

**Flutter/跨端说明：** 官方生态提供 Dart/Flutter 客户端，可在 Android、iOS、Web、Windows、macOS、Linux 的 Flutter 应用中通过网络 API 使用；这不代表仓库提供各平台原生数据库。Windows 完成度主要取决于 Dart SDK 与网络/鉴权流程；桌面密钥不能内置 service_role。打包仍使用 Flutter 各平台工具链，Supabase 不负责签名、安装器或自动更新。

**风险或注意事项：** RLS 配置错误、service_role 泄漏、存储策略和备份恢复是主要风险；自托管需负责数据库升级、邮件、对象存储和可观测性。客户端永远只放匿名公钥，敏感管理操作置于可信后端。
