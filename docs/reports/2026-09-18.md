## 1. WeKnora

- **仓库地址：** https://github.com/Tencent/WeKnora
- **官网：** https://weknora.weixin.qq.com
- **主语言/技术栈：** Go；Vue 3.5、TypeScript、Vite、Pinia、TDesign；RAG、向量检索、MCP。
- **主题标签：** AI、Vue、TypeScript、知识库、私有部署、Agent、Wiki。
- **许可证：** 自有代码 MIT；第三方组件遵循各自许可证。API 返回 NOASSERTION，但已直接复核 LICENSE 的 MIT 条款与第三方声明，不能据此将全部依赖视作 MIT。
- **当前 Star：** 26,172。
- **近期 Star 增长：** 日榜显示 **+1,125 stars today**（精确页面快照）。
- **首次发布/最近更新：** 仓库创建于 2025-07-22，首次 Release 未核定；最近推送 2026-09-17 16:55:44 UTC；最近正式版本 v0.8.0，发布于 2026-09-03。

**简要介绍：** 将原始文档变成可检索问答、推理代理和可持续维护 Wiki 的知识平台。

**详细介绍：** 它不只提供文件上传和向量检索，还将知识库、带工具调用的代理和 Markdown Wiki 放在同一产品中。Vue 前端包含文档预览、检索结果引用和知识图谱等工作流；后端面向多租户、工作空间权限和不同模型供应商。适合研究 Vue 与 AI 的产品整合，而不仅是调用一次聊天 API。

**核心能力：** 文档解析与检索、ReAct Agent、MCP 工具、沙箱技能执行、Wiki 页面生成及修订、多工作空间 RBAC、数据源连接和可观测性。

**适用场景：** 团队技术文档问答、内部知识平台、研究资料管理，以及 Vue 管理端与 RAG/Agent 的集成参考。

**为什么近期快速上升：** 日榜增量显著；近期版本围绕自动标签、附件解析、邀请权限和 SSRF 防护改进，持续提交强化了从知识问答到代理/Wiki 的完整工作流。推断其热度与功能完整性、私有部署需求相关。

**活跃度与成熟度：** 生成前一天仍有推送，已有连续 0.x 版本；功能覆盖广但仍处快速演进阶段。新能力应区分 main 分支与已发布版本，不能直接认为最新 README 全部进入 v0.8.0。

**风险或注意事项：** 外部文档提示注入、URL 抓取 SSRF、模型密钥与多租户隔离需要重点评审；沙箱须限制网络和主机权限。自托管不等于所有模型请求留在本机；第三方组件许可须单独核对。

## 2. Octop

- **仓库地址：** https://github.com/TencentCloud/Octop
- **官网：** https://octop.cloud
- **主语言/技术栈：** Python 3.12+、FastAPI、React 18/TypeScript/Vite、SQLite/PostgreSQL、Harness Agent、APScheduler。
- **主题标签：** AI、Python、TypeScript、多用户、多代理、Windows、跨平台、自托管。
- **许可证：** MIT。
- **当前 Star：** 3,420。
- **近期 Star 增长：** 日榜显示 **+367 stars today**（精确页面快照）。
- **首次发布/最近更新：** 仓库创建于 2026-07-08，首次 Release 未核定；最近推送 2026-09-17 13:31:22 UTC；v1.0.0 GA 发布于 2026-09-14。

**简要介绍：** 面向个人、家庭与小团队的多用户、多代理自托管助手。

**详细介绍：** 一个进程同时提供 Web 控制台、CLI、IM 通道和定时任务，以本地 SQLite 为默认控制平面数据库，也允许 PostgreSQL。不同用户可拥有专属代理与持久化记忆，连接器通过 OAuth/MCP 扩展外部能力，ACP 将助手接入开发工具。前端是 React，不是 Vue；未将其误标为 Electron 或 Flutter。

**核心能力：** RAG、专家库、持久记忆、飞书/钉钉/QQ/Discord/企微接入、浏览器自动化、终端工具、远程桌面、工具审批、JWT 用户隔离和 cron。

**适用场景：** 本地 AI 工作台、小团队共享助手、开发者自动化和多通道定时任务。

**为什么近期快速上升：** 高日增长叠加本周 GA 发布；安装包降低了自托管门槛，多入口共享同一代理状态形成了可实际使用的产品体验。热度来源为分析推断。

**活跃度与成熟度：** 前一天仍有推送，已有 1.0.0，但仓库仅创建两个月；GA 标记不能替代真实负载、安全和升级验证。

**Windows 与跨端：** Release 提供 Windows x64/ARM64 安装及便携包、macOS Intel/Apple Silicon、Linux x64/ARM64。移动设备可访问 Web 控制台；本次未确认 Android/iOS 原生客户端。不是 Flutter 项目，无须据此推断 Flutter 插件兼容性。

**风险或注意事项：** 远程桌面、浏览器和 shell 都具有高权限，应限定授权、隔离存储与网络；凭据备份需加密。自托管控制平面不保证外部模型、IM 和连接器数据不出网。签名与自动更新安全未在本次实测。

**来源：** [日榜](https://github.com/trending?since=daily)、[README](https://github.com/TencentCloud/Octop#readme)、[GA 与安装资产](https://github.com/TencentCloud/Octop/releases/tag/v1.0.0)、[许可证](https://github.com/TencentCloud/Octop/blob/main/LICENSE)。

- **主题标签：** C#/.NET、Windows、原生互操作、手机投屏、OBS、跨设备。

**简要介绍：** Windows 上本地 USB/AirPlay iPhone/iPad 投屏及可选蓝牙反向控制工具。

**详细介绍：** WPF 主程序处理设备列表和会话；C++ 核心负责私有 USB 协议、媒体解析、解码与原生渲染，独立无线宿主传递 AirPlay 帧，驱动维护由单独程序承担。这种边界划分适合参考 C# UI 与底层多媒体/驱动互操作，不能当作通用 Flutter 跨端 SDK。

**适用场景：** 手机演示、录制直播、Windows 桌面多媒体开发研究；Vue/Flutter 手机项目演示时可作为外围工具。

**为什么近期快速上升：** 两个月的新项目周增量相对显著，本地双通道和 Windows 原生显示切中需求；最近正式版修复升级后 libusb0.dll 发现问题。增长与这些能力的关联为推断，不称其当天新版本。

**Windows 限制与发布：** 官方仅 Windows 10/11 x64，ARM64 因驱动/无线运行库缺失不支持；无商业 Authenticode 签名，可能触发 SmartScreen。需要对应 USB 驱动和解码运行库；蓝牙反控依赖 iOS 辅助触控与 Windows 外设模式，不能注入多指触控。

**风险或注意事项：** Apple 私有协议可能随 iOS 更新失效；驱动安装有系统权限与兼容风险。GPL 分发义务须核对，不能直接复制为闭源商用组件；设备录屏注意隐私。

- **主题标签：** C#/.NET、Windows、插件架构、本地数据、桌面应用。

- **当前 Star：** 14,015。
- **近期 Star 增长：** C# 周榜显示 **+93 stars this week**（精确页面快照；相对成熟项目属温和持续增长，不宣称爆发）。

**简要介绍：** 将多个游戏平台和模拟器游戏统一到一个 Windows 本地库和启动器。

**详细介绍：** 主应用保管本地游戏库，插件接入 Steam、Epic、GOG 等第三方库，再通过统一界面浏览与启动。它的价值还在于成熟 .NET 桌面应用如何隔离业务集成、主题和脚本扩展，可为自己的 C# Windows 工具提供架构参考，而不是仅作为游戏软件推荐。

**核心能力：** 多平台库导入、模拟器支持、统一启动入口、.NET 插件、PowerShell 脚本、主题、本地库存储和版本通知。

**风险或注意事项：** 登录 Cookie/令牌会由平台插件保存，插件权限和供应链须审查；当前公开代码不能用于推断 11 版架构。遵守游戏平台服务条款及游戏资源授权。
