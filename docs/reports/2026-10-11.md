- **Flutter 平台支持：** **Windows：正式支持**（Windows 10+ x64，有安装包和原生窗口/剪贴板/拖放实现）；**macOS：正式支持**（Apple silicon、Intel）；**Android / iOS / Web：未声明支持、无对应应用 Runner**；**Linux：仅提供 SSH 远端服务端，桌面 GUI 未声明支持**。Windows 功能完成度以仓库文档看较高，但本站未做真实设备测试；原生限制包括 Win32 窗口通道、ConPTY、系统剪贴板/文件拖放及外部 Claude Code CLI。源码构建须 Flutter、MSVC Build Tools 2022、Windows 10 SDK；安装包脚本还需 Inno Setup，签名与自动更新依赖其发布流水线及下载端点，不能只靠 flutter build windows 完成正式发行。
- **潜在风险或注意事项：** Claude Code 登录/许可及模型费用由用户自行承担；GPL 主应用与 MIT 子包许可不同；远程 SSH、代理模型密钥和自动更新需审查。
