- **适用场景**：Windows 数据库开发、轻量 DBA 工具、Flutter + Go FFI 桌面架构、SQL Agent 人机确认设计。
- **为什么近期快速上升**：日增 14，对不足 800 Star 的项目增速明显；“Flutter 原生桌面 + 多数据库 + AI SQL”与跨端开发者和数据库工程师的需求高度重合。
- **活跃度与成熟度**：已有 0.13.0，Windows 与 macOS 安装包可下载；版本仍小于 1.0，Linux 虽在 README 标为支持，但最新 Release 资产只列出 Windows x64 与 macOS ARM64。
