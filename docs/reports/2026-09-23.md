## 1. AX

- **项目名称 / 仓库：** AX — https://github.com/google/ax
- **官网：** https://agentexecutor.io
- **主语言/技术栈：** Go、Kubernetes、gRPC、Redis、Agent Substrate、YAML 声明式资源。
- **主题标签：** AI Agent、任务编排、沙箱、网络隔离、集群运行时。
- **许可证：** Apache-2.0。
- **当前 Star：** 7,557。
- **近期 Star 增长：** 综合日榜 **+2,305 stars today**（精确页面快照）。
- **首次发布/最近更新：** 仓库创建于 2026-03-30；首次 Release 未核定；最近推送 2026-09-20 03:33 UTC；v0.3.0 同日发布。

**简要介绍：** Google 开源的声明式 Agent 工作负载编排运行时。

**详细介绍：** AX 以类似 Kubernetes 的资源模型描述 Task、Workspace、Gateway 和 Model，为 Agent 准备代码仓库、MCP 与技能，限制计算资源和外网访问，并支持观察、进入、暂停与恢复任务。它面向集群里的长时、有状态 Agent，不是应用层聊天框架。

**核心能力：** 沙箱任务、预热工作区、出站域名白名单、模型凭据、资源限制、任务观察、挂起/恢复和 SSH 调试。

**适用场景：** 大规模编码 Agent、受控自动化任务、企业内部 Agent 基础设施和 Kubernetes 运维研究。

**为什么近期快速上升：** +2,305 的日榜信号显著，且 v0.3.0 刚发布。推断 Google 背景和“Agent 运行时/隔离”需求共同推动关注，但不能证明单一事件是全部增量来源。

**活跃度与成熟度：** 0.3.x、核心协议仍在调整；README 明确警告稳定版前可能出现重大破坏性变更。

**风险或注意事项：** 部署依赖 Kubernetes、镜像仓库及 Agent Substrate，运维门槛较高。网络白名单和沙箱不能代替凭据最小权限、计费上限与审计；Agent 仍可能循环消耗模型费用。不要把宣称的“billions”吞吐当成自己的环境已验证容量。

**来源：** [Trending](https://github.com/trending?since=daily)、[README](https://github.com/google/ax#readme)、[v0.3.0](https://github.com/google/ax/releases/tag/v0.3.0)、[许可证](https://github.com/google/ax/blob/main/LICENSE)。
