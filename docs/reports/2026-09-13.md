## 1. DeskcommCRM

- **仓库地址：** https://github.com/melgarafael/DeskcommCRM
- **官网：** https://deskcomm.com.br
- **主语言/技术栈：** TypeScript、Next.js 16、Supabase（PostgreSQL/Auth/Storage）、Docker、WAHA、LLM API
- **主题标签：** AI、AI Agent、CRM、WhatsApp、RAG、MCP、自托管、多租户
- **许可证：** MIT
- **当前 Star：** 1,795
- **近期 Star 增长：** GitHub Trending 当日快照显示 **+152 Star/天（精确快照值）**；生成时仓库总 Star 已高于快照中的 1,421，说明榜单刷新后仍在快速增长。
- **首次发布/最近更新：** 仓库创建于 2026-04-28；最近提交 2026-09-12；最新版本 [v1.19.0](https://github.com/melgarafael/DeskcommCRM/releases/tag/v1.19.0) 发布于 2026-09-11。

**简要介绍：** 面向 WhatsApp 销售和客服场景的开源、自托管 CRM，把 AI Agent、客户会话、销售流程和自动化集中在一个系统内。

**详细介绍：** DeskcommCRM 以 Next.js 与 Supabase 为核心，支持通过 WAHA 或 Meta 官方通道接入 WhatsApp，并允许连接 OpenAI、Anthropic、OpenRouter 等模型。项目提供 Docker/VPS 部署脚本、HTTPS、数据库初始化、管理员创建、定时自动化与版本更新流程，目标是形成可独立掌控数据的销售操作系统，而不只是聊天机器人外壳。

**核心能力：** 多租户 CRM、AI 自动接待与线索筛选、WhatsApp 会话、RAG/MCP 集成、销售自动化、PostgreSQL 数据持久化、Docker 自托管、备份与版本回滚。

**适用场景：** 中小企业销售团队、WhatsApp 客服、私域运营、需要自托管数据的垂直 CRM，以及希望在 TypeScript 技术栈中集成 AI Agent 的团队。

**为什么近期快速上升：** 当日进入 TypeScript Trending 前列，并在短时间获得三位数新增 Star；v1.19.0 刚发布，安装和升级路径较完整，AI Agent + WhatsApp + 自托管 CRM 的组合具有清晰业务落地价值。

**活跃度与成熟度：** 最近一天仍有提交，拥有版本发布、CI、架构与运维文档；当前 121 个开放 Issue 表明使用面扩大，也意味着维护压力较高。

**潜在风险或注意事项：** 生产部署涉及 Supabase、模型密钥、WhatsApp 通道、域名和 VPS；一键脚本应先审计再执行。WAHA/WhatsApp 自动化需评估平台条款、账号封禁、隐私和当地合规要求。README 含商业合作链接，部署选型应独立评估。

**适用场景：** AI Agent 工程研究、交易自动化原型、TypeScript 多工具编排、预测市场数据研究，以及需要本地运行交易助手的高级用户。

**潜在风险或注意事项：** 涉及真实资金、私钥和交易所密钥，存在市场、代码、权限、供应链及合约风险；默认应使用模拟账户、最小权限密钥、提款禁用、金额上限和独立运行环境。任何策略描述都不是投资建议。

- **许可证：** MIT
- **当前 Star：** 3,025

**简要介绍：** 面向 Agent 的研究知识库工具，把网页/PDF 抓取、来源分析、多角度草稿、批评校验、引用核查和 Markdown 归档串成可复用流程。

**详细介绍：** hyperresearch 不只生成一次性报告，而是把来源、笔记、关系和研究结果保存为 Markdown，并使用可重建的 SQLite 索引提供搜索、反向链接、去重与生命周期管理。其工作流按角色拆分抓取、来源分析、深挖、综合、批评、补丁和引用核验，适合需要长期积累的技术调研，而不是把每次 Agent 执行当作孤立会话。

**核心能力：** 并行来源抓取、PDF 提取、多 Agent 深度研究、引用核验、持久知识库、全文/可选语义搜索、笔记状态管理、去重和知识图谱连接。

**适用场景：** 技术选型、竞品研究、论文/行业资料整理、长期项目知识库，以及用 Python 扩展 Agent 研究流水线。

**为什么近期快速上升：** Python Trending 当日新增超过 150 Star；v0.11.1 刚发布，“可持续积累的研究库”解决了普通深度研究结果难复用的问题。

**活跃度与成熟度：** 最近一天有提交，版本迭代至 0.11.1，11 个开放 Issue；工作流设计完整，但 0.x 版本意味着接口和数据组织仍可能变化。

**潜在风险或注意事项：** 默认流程依赖特定 Agent/模型能力，运行成本和时间可能较高；网页抓取可能受登录、反爬、版权和站点条款约束。长期使用前应验证 Markdown 与 SQLite 重建、引用可访问性及模型供应商替换能力。
