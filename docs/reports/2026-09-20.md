## 1. json-render

- **项目名称 / 仓库：** json-render — https://github.com/vercel-labs/json-render
- **官网：** https://json-render.dev
- **主语言/技术栈：** TypeScript、JSON Schema/Zod、React/Vue/Svelte/Solid 渲染器、React Native、Next.js。
- **主题标签：** AI、生成式 UI、Vue、TypeScript、跨端界面。
- **许可证：** Apache-2.0。
- **当前 Star：** 16,849。
- **近期 Star 增长：** TypeScript 日榜 **+585 stars today**（精确页面快照）。
- **首次发布/最近更新：** 仓库创建于 2026-01-14；首个 Release 未核定；最近推送 2026-09-18 18:53:03 UTC；v0.21.0 同日发布。

**简要介绍：** 让 AI 在预定义组件和动作目录内生成可校验 JSON，再安全地渲染为界面。

**详细介绍：** 应用定义组件目录、props schema 和允许的动作，模型只能在这些边界内组合 UI；流式结果可渐进展示。它提供 Vue 渲染器，也覆盖 React、Svelte、Solid 和 React Native，但“同一目录跨端”不等于各平台组件可无差别复用。

**核心能力：** Schema 约束、组件白名单、动作注册、流式渲染、预构建 shadcn/ui 组件、Next.js 应用与 PDF/邮件/视频等专用渲染器。

**适用场景：** Vue 3 管理端的动态表单、AI 仪表盘、可控的智能工作流界面，以及对比多端生成式 UI 实现。

**为什么近期上升：** +585 的日榜信号突出；v0.21.0 新增 TanStack Start 渲染器，并加强 Vue 命名插槽和 React 流式稳定性。推断多框架支持与可控生成契合近期需求，不能证明单一版本是全部增长原因。

**活跃度与成熟度：** 有持续提交和正式发布，但仍为 0.x；各渲染器成熟度不同。版本变更前要核对 Vue 命名插槽和动作事件契约。

**风险或注意事项：** 白名单和 schema 减少任意组件注入，但动作执行仍需鉴权、权限和输入校验；不可信生成内容需防 XSS、越权和意外网络请求。移动端、PDF、邮件渲染能力应按各自包测试。

**来源：** [Trending](https://github.com/trending/typescript?since=daily)、[README](https://github.com/vercel-labs/json-render#readme)、[v0.21.0](https://github.com/vercel-labs/json-render/releases/tag/v0.21.0)、[许可证](https://github.com/vercel-labs/json-render/blob/main/LICENSE)。

- **主题标签：** AI、Python、RAG、长文档、树检索、本地模式。
- **许可证：** MIT。
- **当前 Star：** 35,757。

**适用场景：** 合同、技术手册、财报等长文档的检索实验，或为 Python 后端的 Vue/Flutter 前端提供文档问答能力。
