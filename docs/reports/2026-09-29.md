**简要介绍：** 面向 Apple Silicon 与 NVIDIA GPU 的本地文本模型服务，通过逐模型家族的内核和草稿验证，提升解码效率并提供常见客户端可接入的 API。

**详细介绍：** 项目并非给现有服务套一层代理，而是针对模型家族实现投影、缓存、草稿和验证路径。草稿 token 只有在等于同一引擎串行执行将产生的 token 时才接受；“exact”限定在**相同引擎、权重、运行时和采样设置**，不表示 MLX 与 CUDA、不同量化精度或不同张量并行数的输出逐位相同。MLX 和 CUDA 的并发、缓存及上下文能力也有差异，需要按具体模型路径选配置。

**核心能力：** OpenAI-compatible 模型服务；模型下载与配置检查；推测解码/MTP；部分模型并发调度；上下文和显存准入；MLX 对话前缀保留与可选磁盘溢出；支持部分混合位宽与实验性 EXL3 权重。

**适用场景：** Python 本地 AI 工具、Mac 开发机模型服务、受控 NVIDIA 环境中的推理实验、需要对比草稿解码与串行结果的性能评估。

**活跃度与成熟度：** 当日有正式 Release 和内核/缓存提交，约 20 个开放 issue；仍为 0.3.x，部分格式与硬件组合明确标注实验性或待资格验证。它是活跃的性能工程项目，不是已验证所有消费级显卡、内存配置的通用部署方案。
