- **详细介绍 / 核心能力 / 适用场景：** 在同一作品内管理章节、世界观、人物和剧本，进一步使用画布与 3D 导演台规划镜头、多轨剪辑导出成片；本地 SQLite 保存资料，可自选模型 API。适合作者或小型内容团队探索从文字到视听草稿的跨端生产，但功能广度和稳定性需要按实际版本逐项验证。
- **为什么近期快速上升：** 新仓不到一周达到 152 Star，且很快提供三个平台的 v0.3.0 包；Flutter 本地优先 AI 创作应用与 Windows 桌面发行结合较少见。
- **活跃度与成熟度：** 有实际安装包和较完整的模块文档，但版本仍是 0.3.x；性能、跨平台一致性、作品数据迁移及媒体导出可靠性均未独立测试。
- **潜在风险 / 注意事项：** 模型 API 与生图/生视频可能产生费用并处理未公开作品；本地工程与 SQLite 数据需定期备份。AGPL 与多媒体/字体/模型资产的授权应分别核对，商用前需评估许可证义务。
- **Flutter 平台与 Windows 完成度：** **Windows 10/11 x64、macOS 12+ Apple Silicon 和 Android 8+ ARM64 有 v0.3.0 发行包**；**iOS、Web 未见发行包或明确支持**，Linux 虽在开发命令中出现，但本次未见 Linux 发行包，记为未验证。Windows 已有 `-setup.exe`，可认定具备预览级桌面交付，不能认定所有剪辑/3D/模型功能完成。桌面端依赖 Flutter 桌面工具链、FFmpeg Kit/FVP 等原生媒体能力与图形硬件；从源码打包需 Flutter/FVM、代码生成及 Windows 原生构建环境，签名与自动更新条件未见可核实承诺，发布前须自行检查。
