- **简要介绍**：在自有机器上运行 Cloudflare Workers 与 Durable Objects，并用每对象一个 SQLite 数据库和 S3 兼容存储实现持久化与迁移。
- **详细介绍**：每个命名对象对应独立 SQLite，节点把状态持续复制到 S3/R2；节点只通过对象存储中的所有权记录协调，无独立控制面或共识集群。新节点可恢复并接管休眠对象，应用按对象天然分片，空闲 Cell 会休眠以降低资源占用。
- **核心能力**：Wrangler Bundle 执行；V8 嵌入；每对象 SQLite；S3/R2 复制；租约所有权；节点替换与休眠恢复；容器镜像；诊断与压力卸载。
- **适用场景**：TypeScript/JavaScript 有状态服务、可自托管 Durable Objects、边缘状态机、多人协作对象、按实体分片的小型数据库工作负载。
- **为什么近期快速上升**：日增 516 Star且 v0.1.0 刚发布；它把受欢迎的 Durable Objects 编程模型带到自有基础设施，并以“对象存储协调、无控制面”形成鲜明架构差异。
- **活跃度与成熟度**：由 Deno 官方组织维护，文档覆盖安装、容器、部署、安全和诊断；但首版发布仅三天，生产经验与故障边界尚少。
- **潜在风险或注意事项**：Peer HTTP 不终止 TLS，官方要求放在可信私网或 WireGuard/Tailscale 上；S3 凭据等同集群管理员权限。架构依赖对象存储的比较交换语义，跨区延迟、冲突、成本、灾备与大对象负载必须压测。
- **来源链接**：[GitHub](https://github.com/denoland/celld) · [官网与文档](https://celld.dev) · [README](https://github.com/denoland/celld/blob/main/README.md) · [v0.1.0](https://github.com/denoland/celld/releases/tag/v0.1.0) · [Trending](https://github.com/trending?since=daily)
